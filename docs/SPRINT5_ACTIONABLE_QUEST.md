# Sprint 5 — Actionable Quest Slice

> Status: Design（故事脊椎已定调）  
> Concept: **Learning Adventure**  
> Story tone: **B · 轻奇幻** — 异步之城 · 时间法则

> AI / 完整 IDE: 不做

---

## 0. 故事脊椎（串联所有学习内容）

### 0.1 为什么需要故事线

知识点列表无法给人「继续往下走」的理由。故事线是学习系统的**脊椎**：

```text
故事卷（World）
  └── 章节事件（冲突）
        └── Adventure 关（行动 → 世界状态变化）
              └── Knowledge / Mastery（沉淀）
```

用户感知的是「我在推进故事」；系统记账的仍是能力证据。

### 0.2 世界观（Tone B · 轻奇幻）

| 元素 | 设定 |
|---|---|
| 世界 | **异步之城（Async City）** — 万物靠「约定（Promise）」与「时序律法」运转 |
| 危机 | **时间错乱** — 该先后的事颠倒，城中机关失灵 |
| 主角 | **你** — 初入城的时序学徒（第二人称） |
| 成长 | 每修复一处错乱，掌握一条 **时间法则**（= Knowledge） |
| 卷 | Async World = **第一卷《时序初章》**；未来其他前端主题 = 其他城区/卷 |

气质：轻奇幻比喻 + 仍能看见「支付/订单」这类可读状态（奇幻外壳，工程内核）。

### 0.3 第一卷章节地图（规划，本 Sprint 只做第 1 章）

| 章 | 事件名 | 时间法则（知识点） | Sprint |
|---|---|---|---|
| 序 | 双钮之谜 | 立即 vs 稍后（直觉） | 可选极短引导 |
| **1** | **金库契约断裂** | Promise 链顺序 | **S5 P0** |
| 2 | 永转的水车 | 未结束的异步 / 错误 | 后 |
| 3 | 乱序的驿报 | 竞态 | 后 |
| 4 | 钟楼错拍 | 宏任务 / 微任务 | 后 |
| 末 | 城门联防（Boss） | 综合 | 后 |

规则：

1. 一章 = 一个冲突 + 一次「你动手修好」  
2. 旁白短，**推进靠行动，不靠长对话**  
3. 已通关章节可回放；刻意练习可进「训练室」（旧选择题归处）

|---|---|
| Quest = 题 | Quest = 章节里的一次修复任务 |
| 点选项 | 受控操作 + **唤起（Run）** |


## 5. 第 1 章骨架《金库契约断裂》

### 5.1 剧情（短）

**引子（intro）**

```text
异步之城 · 金库区

市民已将金币纳入「支付契约」，契约显示完成。
但台账未翻页，库房库存符文未熄——时间链在中途断了。

你是时序学徒。重排契约上的誓约顺序，再唤起时序，看城是否恢复。
```

**失败旁白（示例）**

```text
时序被唤起……支付之契亮起，台账仍沉睡。
链上有誓约站错了位置。再排一次。
```

**成功旁白（示例）**

```text
台账翻页，库房符文熄灭。金库重新顺从时间。

法则铭刻：Promise 链按 then 的衔接依次落下；
顺序错了，后面的誓约不会自动补上前面的结果。
```

### 5.2 状态面板（世界反馈）

| 符文位 | 失败 | 成功 |
|---|---|---|
| 支付契约 | ✅ 已完成 | ✅ 已完成 |
| 订单台账 | ❌ 未翻页 | ✅ 已记录 |
| 库存符文 | ❌ 仍亮着 | ✅ 已扣减 |

### 5.3 状态机

```text
intro → lab → running → failed ⇄ lab
                      ↘ success → hub / 预告第 2 章
```

### 5.4 受控操作（待你最终锁一种）

| 方案 | 操作 |
|---|---|
| **A 排序（推荐）** | 重排 then 链上的步骤卡片 |
| B 填空 | 在 TODO 选择正确誓约 |

步骤卡片示例名（奇幻名 + 可对照代码）：

1. 确认支付（payment）  
2. 翻开台账（createOrder）  
3. 熄灭库存符文（updateInventory）  

错误初始顺序：例如 支付 → 库存 → 台账，导致台账/库存异常。

### 5.5 判定

操作快照 → 确定性结果；不执行任意代码；可写入 progress / evidence。
