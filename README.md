# Frontend Quest

把前端知识练成可闯关的能力。当前 MVP：**Async World**（本地可玩）。

## 快速开始

```bash
npm install
npm run dev
npm test
```

清档重测：

```js
localStorage.removeItem('frontend-quest:save');
location.reload();
```
