# Frontend Quest

Story-driven frontend ability training. Current slice: **时序城 · 粮仓事故**.

## Quick start

```bash
npm install
npm run dev
npm test
```

Clear save:

```js
localStorage.removeItem('frontend-quest:save');
location.reload();
```
